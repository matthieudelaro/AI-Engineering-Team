# AutoGe agent instructions

Before working in this directory:

1. Follow the repository root `AGENTS.md` and `context/TEAM-INSTRUCTIONS.md`.
2. Read `START-AGENT.md`, `MEMORY.md`, `PROJECT-BRIEF.md`, `CRITERIA.md` and the
   latest shortlist/report.
3. For the complete operating cycle, read
   `skills/auto-ge-operator/SKILL.md` and
   `playbooks/002-daily-review-and-sourcing.md`.
4. For any Auto.ge message interaction, also read
   `skills/auto-ge-messaging/SKILL.md` and
   `playbooks/001-auto-ge-messaging-playwright.md`.

Write reports only in English. Inbox review, reporting and vehicle research are
read-only. Draft and send seller messages only in the seller's detected language
(normally Georgian), and always show the original-language draft with an exact
English translation. Never send unless the user approves that exact text and
destination in the active task. After one approved click, verify delivery through
a fresh conversation-history read and never retry automatically.

Keep credentials in Chrome. Never inspect or persist cookies, browser storage,
passwords or session identifiers. Store downloaded artifacts only under ignored
`data/`; keep synthesized reports, skills and playbooks in Git.
